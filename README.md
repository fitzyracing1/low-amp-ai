# Low-amp AI

> **Status:** Just an idea. No code.

A guide and tool for running agents on less power: fewer server calls, fewer scheduled jobs, short answers by default, full power only when a task needs it.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (A bot, Oct 21 2026) and was not taken further at the time. This repo records it so it can be picked up later.
